## AI全栈工程师

### 岗位职责

1. 负责公司 AI 产品的全栈研发，参与前端、后端及 AI 工程化能力建设，推动产品从需求到上线的完整交付。
2. 负责 Web 端功能开发及交互体验优化，参与模型管理、知识库、Agent、智能问答等产品功能建设。
3. 负责后端服务及 API 设计开发，建设高可用、可扩展的业务服务，并对接内部大模型推理服务及主流大模型 API。
4. 参与 RAG、Agent、知识库、记忆库、AI Coding 等 AI 应用能力的工程化落地。
5. 负责大模型流式输出、会话管理、模型调用、权限及相关业务功能开发，持续优化响应速度和产品体验。
6. 与产品、算法及平台团队协作，完成复杂需求的技术方案设计、开发及问题定位，持续探索 AI 新场景。

### 任职要求

1. 本科及以上学历，计算机相关专业，3 年以上全栈或后端开发经验，有 AI 应用或大模型项目经验优先。
2. 熟练掌握 JavaScript / TypeScript，熟悉 React 或 Vue 等至少一种主流前端框架，能够独立完成复杂 Web 功能开发。
3. 熟悉 Go / Java / Python 中至少一种后端开发语言，具备良好的 API、服务端架构及工程开发能力。
4. 熟悉 MySQL、PostgreSQL、Redis 等常用数据库及中间件。
5. 了解大模型基本原理和调用方式，有 OpenAI 兼容 API、SSE/WebSocket 流式输出、Prompt、RAG、Agent 等实际开发经验。
6. 具备良好的工程能力和问题分析能力，能够独立负责功能从方案设计、前后端开发到上线落地。
7. 对 AI 新技术和产品有兴趣，具备较强的自驱力、学习能力和团队协作能力。

### 加分项

* 有知识库、RAG、Agent、AI Coding、企业智能问答等产品研发经验；
* 熟悉 LangChain、LangGraph、LlamaIndex、Dify 等 AI 应用框架；
* 熟悉向量数据库及 Embedding、Chunking、召回等 RAG 基础技术；
* 有 Docker、Kubernetes 等容器化项目经验，具备应用容器化部署及问题排查能力；
* 了解 KServe、SGLang、vLLM 等大模型推理服务；
* 有 ToB 产品、私有化部署或从 0 到 1 产品研发经验。
